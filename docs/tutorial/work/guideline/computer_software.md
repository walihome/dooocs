# 新员工软件安装指南

欢迎加入我们的团队！以下是你可能需要安装的一些软件。

## 操作系统

- **Windows 10** 或 **MacOS Big Sur**：我们的工作环境支持这两个操作系统。

## 开发工具

- **Java**: 我们的一些项目需要 Java，你可以从[这里](https://www.oracle.com/java/technologies/javase-jdk11-downloads.html)下载最新版本的 Java 开发工具包 (JDK)。

- **Maven**: 这是一个用于管理 Java 项目的工具，你可以从[这里](https://maven.apache.org/download.cgi)下载。

- **IntelliJ IDEA**: 这是一个用于 Java 开发的集成开发环境 (IDE)，你可以从[这里](https://www.jetbrains.com/idea/download/)下载。

- **Python**：我们的大部分工作需要 Python，你可以从[这里](https://www.python.org/downloads/)下载最新版本。

- **Anaconda**：这是一个包含了许多常用科学计算库的 Python 发行版，你可以从[这里](https://www.anaconda.com/products/distribution)下载。

- **Visual Studio Code**：这是一个功能强大的代码编辑器，你可以从[这里](https://code.visualstudio.com/)下载。

- **Git**：我们使用 Git 进行版本控制，你可以从[这里](https://git-scm.com/downloads)下载。

## 办公软件

- **Microsoft Office**：我们的日常工作中会使用到 Office，包括 Word、Excel 和 PowerPoint。

- **Slack**：我们使用 Slack 进行团队内部的即时通讯，你可以从[这里](https://slack.com/intl/en-cn/downloads)下载。

- **Zoom**：我们使用 Zoom 进行视频会议，你可以从[这里](https://zoom.us/download)下载。

如果你在安装过程中遇到任何问题，请随时向我们求助。
