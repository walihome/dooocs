# CSS `position` 属性值对比速查表

| 特性 / 对比点          | `static` (老实人) | `relative` (微调达人) | `absolute` (自由飞鸟) | `fixed` (钉子户) | `sticky` (粘人精) |
| :--------------------- | :---------------- | :-------------------- | :-------------------- | :--------------- | :---------------- |
| **是否脱离文档流？**   | 否                | 否                    | **是**                | **是**           | **否 (初始)** / 部分是 (粘住时) |
| **是否占据原空间？**   | 是                | 是                    | **否**                | **否**           | **是 (初始)** / 行为类似不占 (粘住时，但影响布局计算) |
| **`top/right/bottom/left` 是否生效？** | **否**            | 是                    | 是                    | 是               | 是 (主要用于定义"粘住"的阈值) |
| **定位参照物 (基准点)** | 无 (随文档流)     | **自身原始位置**      | **最近的"非`static`"祖先** | **浏览器视口 (Viewport)** | **滚动容器 / 视口** (当达到阈值时) |
| **找不到参照物时的后备？** | N/A               | N/A                   | **初始包含块** <br>(通常基于`<html>`或`<body>`) | N/A              | N/A (总有滚动容器) |
| **`z-index` 是否生效？** | **否**            | 是                    | 是                    | 是               | 是 |
| **元素随页面滚动行为** | 正常滚动          | 正常滚动 (偏移量不变) | **随"参照物"滚动**    | **不滚动 (固定在屏幕)** | **滚动至阈值时"粘住"，<br>超出父容器后随父容器滚动** |
| **能否成为`absolute`子元素的定位参照物？** | **否**            | **是**                | **是**                | **是**           | **是** |
| **常见用途**           | 默认布局          | 微调元素位置<br>创建定位上下文 | 覆盖层、弹窗<br>精确布局<br>(需配合参照物) | 固定导航栏/页脚<br>回到顶部按钮<br>模态框背景 | 粘性导航栏<br>表格/列表头<br>侧边栏模块 |
| **核心记忆点**         | 默认，不动        | 占位，微移，当爹 | 脱离，找爹，飞翔 | 脱离，焊屏，无视滚动 | 随流，触点粘，有限范围 |

**表格解读小贴士：**

1.  **文档流 & 占空间：** 这是最关键的区别之一。`absolute` 和 `fixed` 就像飘起来了，下面的元素会无视它们原来的位置。`relative` 还在原地“占坑”，只是样子挪动了。`sticky` 比较特殊，一开始占着，粘住后表现得像 `fixed` 但仍受父级限制。
2.  **定位参照物：** 理解了参照物，你就知道 `top/left` 是相对谁来计算的。这是 `relative`、`absolute`、`fixed` 的核心差异。
3.  **滚动行为：** `fixed` 是完全无视滚动的。`sticky` 是有条件的固定。`absolute` 则依赖于它的参照物是否滚动。
4.  **当爹的资格：** 只要不是 `static`，理论上都能给 `absolute` 的孩子当定位的“靠山”（参照物），但最常用的是 `relative`。
