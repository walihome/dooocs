# 代码组织架构学习

## react目录分别有什用？
package.json 和package-lock.json 是干嘛的？
> 答： 在nodejs项目当中，这两个文件是用来管理项目的依赖和元数据；
> 1）项目元数据包括项目的名称、版本、描述、作者、许可证等；
> 2）项目依赖，比如运行时必须得包；
> 3）脚本，定义了一些可以通过npm run xxx来执行的脚本；4）其他配置，比如支持的一些开发工具等；
>
> package.json主要是用来管理项目元信息以及项目的依赖「是一个范围」等，主要是给开发者看的
> package-lock.json主要是用来管理项目确切的依赖信息，而非是范围，保证项目的重复构建和高效「避免重复搜索依赖范围中可用的依赖」，主要是给npm命令行工具看的。
>
