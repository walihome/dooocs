### 概念 Explanation 🎯

在开始编写Java程序之前，我们需要搭建一个完整的**Development Environment（开发环境）**。就像厨师需要准备好厨房和工具才能做菜一样，程序员也需要准备好编程工具才能写代码！

我们需要安装以下核心组件：
- **JDK (Java Development Kit)** - Java开发工具包 ☕
- **IDE (Integrated Development Environment)** - 集成开发环境 💻

::: tip 为什么需要这些工具？
- **JDK**：包含Java编译器和运行环境，让计算机能理解和执行Java代码
- **IDE**：提供代码编辑、调试、项目管理等功能，让编程更高效
:::
